使用指南

MagicLink 是一个自托管的链接管理站点：每个人的私人收藏，加上团队共享的空间， 再配一个不需要登录就能分享出去的公开页。这份指南按「你会想干什么」组织， 不涉及安装部署（那是部署者的事，见仓库里的 README）。

五分钟上手

  1. 打开 /app，用用户名 + 密码注册（昵称可以留空）。
  2. 左边选「我的链接」，点右上角「新建链接」，把网址粘进去 —— 标题和图标会自动抓取。抓不到就手动填，不影响保存。
  3. 想归类就选一个「分组」；还没有分组的话，在那里新建一个。
  4. 想让某个团队也看到它：同一个弹窗下半部分「链接可见性」里， 勾上那个团队的名字。
  5. 想要一个把链接发给别人、对方不用登录就能看的页面： 去「设置」把「对外公开页」打开。

第 4 步和第 5 步是互相独立的两件事，详见 一条链接会出现在哪些地方。

账号

注册、登录、退出

  • 注册和登录是同一个页面（/app），用下面的链接切换。 对着这个站点是开放自助注册的，不需要邀请。
  • 密码至少 6 位。用户名用来登录，昵称是显示给别人看的名字。
  • 退出按钮在「设置」页。

改密码 / 忘记密码

改密码在「设置 → 基本资料」。忘记密码没有自助入口 —— 这里没接邮件通道，找回需要部署者在服务器上执行： 

python manage.py reset-password <用户名>

不加参数会交互式让你输入新密码，也可以 -p 新密码 直接指定。

用 GitCode 账号登录（可选）

只有当部署者配置了 GitCode 凭据时，登录页和设置里才会出现相关入口； 没配置就完全没有这一项，也不影响用户名密码登录。绑定之后可以一键登录，不用再输密码。

设置里能改什么

这一块能做什么
基本资料改昵称、改密码
GitCode 账号绑定 / 解绑（部署方配了才有）
对外公开页开关公开页，改公开页地址

个人空间

「我的链接」是你的私人收藏。这里的东西默认只有你自己看得到，除非你主动共享或公开。

新建、编辑、删除

  • 新建：粘贴网址后，标题和图标会自动抓取（抓取是访问一次那个网址）。 标题抓不到就用域名兜底，你随时可以改。
  • 备注是可选的，它也会参与搜索。
  • 编辑：卡片上的铅笔按钮。任何一条都能改。
  • 删除：卡片上的垃圾桶按钮，会先问你一次。

分组

  • 分组是空间内部的结构，只影响这个空间的排列，不会变成侧边栏里的东西。
  • 可以新建、重命名、删除，也能拖动调整顺序。
  • 列表上方那排胶囊（全部分组 | 未分组 | 组名 3）用来筛选， 后面的数字是这一组里的链接数。
  • 删除分组不会删掉里面的链接，它们只是变成「未分组」。

拖动排序

卡片左下角有拖拽把手，按住就能调整顺序；分组也能拖。顺序会同步到公开页 —— 想让人先看到哪条，拖上去就行。

搜索

个人空间的搜索框会匹配标题、网址、备注三样内容。

团队空间

一个人可以属于多个团队。左边侧边栏里每个团队一项，后面的数字是成员人数。

创建团队

侧边栏底部「加入 / 创建团队」→「创建」，填个团队名称。创建者自动成为拥有者。

用邀请码加入

  • 每个团队有一个邀请码（10 位字母数字），向拥有者索取。
  • 「加入 / 创建团队」→「加入」，把邀请码填进去。
  • 拥有者可以在「团队设置」里重新生成邀请码：旧的立即失效， 已经加入的成员不受影响。

团队里的链接有两种来源

来源卡片上会标内容归谁维护
在团队空间里直接新建的团队链接 由 谁 添加 团队
成员把自己个人空间的链接共享进来的 来自 谁 本人（是同一份，改一处两边都变）

成员

团队空间右上角「成员」能看到成员列表和各自的角色。拥有者可以把成员移出团队； 被移出的人贡献过的链接会留在团队里，不会跟着人走。

团队分组、团队搜索

跟个人空间一样：分组可以建、可以拖、可以删；搜索匹配标题、网址、备注。

删除团队

只有拥有者能删，在「团队设置」里。删除会一并移除团队链接和共享关系； 成员的个人链接不受影响，它们只是不再出现在这个团队里。

一条链接会出现在哪些地方

每一条链接有两个互相独立的去处，都在编辑弹窗的「链接可见性」里勾选， 没有隐藏状态、也不需要先满足什么条件：

勾选项勾上之后
出现在对外公开页
不需要登录，任何人凭网址可看		 这条链接会汇总到你的（或团队的）公开页上。前提是那个公开页的总开关也开着 —— 总开关没开，勾了也不会出现，弹窗里会当场提示你。
团队名（一个团队一行）
出现在该团队的链接列表		 它进入这个团队的共享空间，队友都能看到。勾上之后还可以选一个团队分组， 不选就是「团队内未分组」。

常见误解：把链接共享给团队 ≠ 它对公众可见。 共享只到团队为止；要让它出现在公开页上，得另外勾「出现在对外公开页」。 反过来说，一条链接也可以只公开、不共享给任何团队。

对外公开页

三种公开页

页面地址内容
链接广场/ 站点首页。把所有已开启的公开空间列成一个目录，谁都能看。
个人公开页/u/<地址> 你个人空间里勾了「出现在对外公开页」的链接，按分组归类。
团队公开页/t/<地址> 团队自有的公开链接 + 成员共享进来、并且本人勾了公开的链接。

怎么开启

  • 个人公开页：「设置 → 对外公开页」打开开关。开启后仍然要逐条 把链接设为「对外公开」，开关本身不会替你决定哪些链接可见。
  • 团队公开页：「团队设置 → 对外公开页」，只有拥有者能改。

地址可以自定义

  • 默认地址是你的用户名（个人）/ team-<编号>（团队）。 可以改成更好记的，比如 sunxianlei、doc-team。
  • 规则：小写字母、数字、连字符，长度 2–40，不能以连字符开头或结尾。
  • 不能和别人已用的地址重名，也不能和别人的用户名重名（那会让对方的页面打不开）。
  • 改了地址，老链接不会失效。 系统先按自定义地址找、找不到再退回用户名， 所以之前分享出去的 /u/旧用户名 照样打得开。
  • 把地址填回空，就退回默认地址。

访客看到什么

  • 不需要登录。页面顶部有搜索框（匹配标题、网址、备注）和分组筛选。
  • 顺序跟你这边一致 —— 你在个人空间拖出来的顺序，公开页上就是那个顺序。
  • 内容实时同步：你改了标题，公开页刷新就是新的，不用重新发布。
  • 每张卡片右下角有个复制按钮，一键复制这条链接的备注（没有备注的卡片不显示这个按钮）。

⚠️ 公开页的隐私提醒

  • 公开页默认带 noindex，不会被搜索引擎收录。 但这只是「请求不要收录」，不是访问控制。
  • 任何拿到网址的人都能看，不需要账号。页面本身就是给分享用的 —— 别往里放不该给外人看的东西（内部地址、带 token 的链接、个人信息）。
  • 不想让它被看到了：把总开关关掉，或者取消那几条链接的「对外公开」勾选。 定期检查一下比事后补救省事。

谁能改谁的

团队里只有两种角色：拥有者（创建者）和普通成员。

操作拥有者普通成员
改 / 删自己添加的团队链接✅✅
改 / 删别人添加的团队链接✅❌
改 / 删自己共享进去的个人链接✅✅
改 / 删别人共享进去的个人链接✅（可移出团队）❌
团队设置、邀请码、团队公开页✅❌
移出成员✅❌
删除团队✅❌

共享进来的链接是引用，内容归本人维护 —— 所以别人（包括拥有者）不能改它的标题和网址，只能把它移出团队。

常见问题

为什么我改不了某条链接？

两种可能：那是别人添加的团队链接，或者那是别人共享进来的个人链接。 这两类都只有本人（和团队拥有者）能动，见上一节。

为什么公开页上看不到某条链接？

按顺序查三件事：

  1. 这条链接勾了「出现在对外公开页」吗？
  2. 对应的公开页总开关开着吗？（个人在设置里，团队在团队设置里）
  3. 团队公开页的话，它还在团队里吗 —— 本人取消共享之后就撤下了。

我把公开页总开关关了，之前的勾选会丢吗？

不会。总开关只控制页面本身开不开，每条链接的「对外公开」勾选原样保留， 重新打开开关它们就又出现了。公开页地址也不会因为开关切换而被清掉。

想要的公开页地址提示被占用？

换个别的。提示「和别人的用户名重复」时也一样 —— 因为默认地址就是用户名， 撞上了会让对方的页面打不开，所以系统会拦住。

团队里某个成员不在了，他加的东西还在吗？

还在。把成员移出团队不会删掉他贡献的团队链接；删掉整个团队才会一起移除 （但成员自己个人空间里的链接始终不受影响）。

链接标题抓错了 / 抓不到？

有些站点会挡住抓取，或者本身就是个 JS 渲染的页面。直接手动填就行， 填什么就显示什么，之后随时能改。

我想把某条团队链接留一份到自己空间？

目前界面上没有这个按钮（后端接口已经在了，还没接到界面）。 临时办法：复制它的网址，在「我的链接」里新建一条。
